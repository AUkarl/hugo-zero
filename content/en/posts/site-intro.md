## About MOL Space

MOL Space is a minimalist personal site built with Hugo, combining blog, moments, tools, and studio modules.

## Design Philosophy

### Minimalism

Removing everything unnecessary, letting content take center stage. Clean typography, generous whitespace, restrained color palette.

### Digital Garden

Unlike the linear timeline of traditional blogs, MOL Space is more like a digital garden — ideas are planted, grown, and connected here.

### Bilingual

Full Chinese and English support with one-click language switching. All content has bilingual versions.

## Feature Modules

| Module | Path | Description |
|--------|------|-------------|
| Landing | `/` | Poetry carousel landing page |
| Home | `/home/` | Article card list |
| Moments | `/moments/` | WeChat-style social feed |
| Tools | `/tools/` | Online utility toolkit |
| Studio | `/work/` | Creative project showcase |
| Archive | `/archive/` | Timeline + tag danmaku |
| Mail | `/email/` | Enterprise email login |
| About | `/about/` | Personal intro & contact |

## Tech Stack

- **Hugo** — Lightning-fast static site generator
- **Go templates** — Flexible template system
- **CSS variables** — Theme switching (light/dark/system)
- **Vanilla JS** — Zero-dependency frontend interactions
- **Font Awesome 6** — Icon library
- **Decap CMS** — Optional content management
