## Core Features

### Responsive Design

Perfectly adapted for desktop, tablet, and mobile. Every page is carefully optimized.

### Theme Switching

Supports light, dark, and system-follow modes. User preference persisted via localStorage.

### Multilingual

Full bilingual Chinese/English support covering all pages and interactive text.

### Fast Loading

- Pure static pages, no backend dependencies
- Auto-minified CSS/JS with fingerprint caching
- Lazy-loaded images
- On-demand math formula loading

## Page Modules

### Landing Page
- Poetry carousel (6 configurable quotes per language)
- Theme/language toggle buttons
- Enter key quick navigation

### Article System
- Card-based home list
- Article detail page (TOC, word count, reading time)
- Categories and tags
- Previous/next navigation
- Data-driven author box
- CC BY-NC-SA 4.0 license display

### Moments
- WeChat-style feed
- Post text, images, music, video
- Like and comment features
- Configurable toggles (publish/like/comment)

### Tools
- 10 tool categories
- Data-driven (`data/tools.yaml`)
- Click sub-items for simulated interfaces

### Archive
- Year-grouped timeline
- Tag danmaku (scrolling tag cloud)
- Click tags to filter articles

### Studio
- CSS Grid project cards
- Status labels (In progress/Draft/Done)
- Data-driven (`data/works.yaml` or `params.works`)
