## Why Hugo

Hugo is one of the fastest static site generators in the world. Written in Go, it builds sites in milliseconds.

### Key Advantages

- **Fast** — Hundreds of pages built in milliseconds
- **Flexible templates** — Powered by Go Templates
- **Easy deployment** — Outputs pure static files

## Quick Start

```bash
# Install Hugo Extended
# Windows: winget install Hugo.Hugo.Extended
# macOS: brew install hugo

# Create a new site
hugo new site my-site

# Start development server
hugo server -D
```

## Summary

Hugo is perfect for personal blogs, documentation sites, and portfolios. With a great theme, you can quickly build a beautiful and functional site.
